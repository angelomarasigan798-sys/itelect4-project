# Student Management System

## Project Description

This is a simple TypeScript project that demonstrates interfaces, generic interfaces, generic functions, utility types, and enums. It simulates a basic student management system for users, courses, and submissions.

## Interfaces

- User
- Course
- Submission
- ApiResponse<T>

## Features

- TypeScript Interfaces
- Generic Interface
- Generic Function
- Utility Types
- Enum

## Installation

```bash
npm install
```

## Run

```bash
npx ts-node src/index.ts
```

## Type Checking

```bash
npx tsc --noEmit
```
